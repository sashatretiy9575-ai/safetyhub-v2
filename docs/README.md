# Документация SafetyHub

- [Контент и база данных](content-and-database-workflow.md) — обязательная синхронизация схемы, hosted CMS, snapshot, presentation assets и destructive cutover.

- [Архитектура](architecture.md) — границы приложения, данные и ключевые
  инварианты.
- [Эксплуатация](operations.md) — ежедневная работа, наблюдаемость, Storage и
  регламенты.
- [Backup и restore](backup-restore.md) — создание, проверка и восстановление
  резервной точки.
- [Deployment и домен](deployment.md) — безопасная выкладка, smoke и rollback.
- [Тестирование](testing.md) — локальные, SQL, browser и release gates.

Документация не хранит секреты, дампы, персональные данные, DNS-экспорты или
временные release receipts. Такие артефакты создаются вне репозитория.
